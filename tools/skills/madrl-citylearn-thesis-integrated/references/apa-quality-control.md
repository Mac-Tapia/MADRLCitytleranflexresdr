# APA and Final Quality Control

## APA Control

- Use current APA style throughout.
- Do not use IEEE style.
- Every technical, conceptual, methodological, or antecedent claim needs citation.
- Use `(Autor, año)` for parenthetical citations.
- Use `Autor (año)` for narrative citations.
- Use `(Autor & Autor, año)` for two authors.
- Use `(Autor et al., año)` for three or more authors.
- Every in-text citation must appear in final references.
- Every final reference must be cited in the text.
- Include author, year, title, journal/conference/university, volume, issue, pages, DOI or URL when available.
- Cite doctoral and master's theses as theses, including university and repository when available.
- Cite GitHub repositories as software/source code with author/organization, year when available, repository name, version if available, and URL.
- Cite datasets as datasets with author/organization, year, dataset name, version if available, repository, and URL.
- Cite official web pages such as CityLearn, MARLlib, NREL, OpenEI, and Optuna as technical documentation/software documentation.
- If DOI is absent, use URL.
- If bibliographic data is missing, write `dato bibliografico pendiente de verificacion`.
- If a result is not confirmed, write `resultado no verificado`.

## Final Quality Checklist

Verify:

1. The structure follows Guide N. 02 section 5.1.
2. The report corresponds to a professional/specialization master's thesis.
3. APA is used throughout.
4. IEEE is not used.
5. `Marco_metodologico_MARL` does not appear.
6. `Marco_metodologico_MADRL` appears where required.
7. CityLearn v3 is presented as `CityLearn v3 propuesto`.
8. MARLlib is used only as a proper name.
9. Chapter numbering is correct.
10. Antecedents come from the bibliographic matrix.
11. Theoretical bases have APA citations.
12. Conclusions respond to objectives.
13. Recommendations derive from conclusions.
14. There are no citations without references.
15. There are no references without citations.
16. Variables align with the consistency matrix.
17. KPIs align with energy flexibility, CO2 emissions, and energy costs.
18. No results are invented.
19. Real results, expected results, and results pending validation are clearly separated.
20. Vertical coherence is preserved: problem -> objectives -> methodology -> proposal -> results -> conclusions.
21. Horizontal coherence is preserved: variables -> dimensions -> indicators -> KPIs -> results.
22. Module A information is used directly in Module B.
