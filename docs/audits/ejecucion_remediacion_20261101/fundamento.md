# Fundamento de las correcciones

Consulta web: 2026-11-01, con reconsulta primaria el 2026-11-02 de PoliTO, JMLR, PMC y la ficha doctoral indexada de Oxford. Las fuentes sustentan método y trazabilidad; el código y sus regresiones prueban los defectos y correcciones. Ninguna prescribe los coeficientes v1 ni demuestra superioridad de un backend de Iquitos.
