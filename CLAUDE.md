## Local project harness

Read `docs/architecture/AGENT_HARNESS.md` and `specs/STATUS.md` for current contracts and pending work. Canonical skills live only in `tools/skills/`; local discovery links are generated by `scripts/skills/register_local_skills.ps1`, not global installs. Roles in `.claude/agents/` separate a bounded implementer from a read-only auditor and a coordinator. Load only skills relevant to the task.

The legacy Stop hook that auto-staged and published all changes was disabled on 2026-10-31 by the user's decision (SPEC-012/FR-012.6). `.claude/auto_save.sh` is kept only for history; do not invoke it or re-enable it. Commit and push explicitly, one reviewed phase at a time.
