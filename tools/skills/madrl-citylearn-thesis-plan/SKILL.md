# MADRL CityLearn Thesis Plan Skill

Use this project-local skill only inside this repository to create or update the **Plan de Tesis de Maestría de Especialización o Profesionalizante** under **Guía N. 01 Metodológica**, section 5.1.

Thesis reference title:

> "Multi-Agente de Aprendizaje por Refuerzo Profundo para la Gestión Coordinada de Flexibilidad Energética, Emisiones de Carbono y Costos Energéticos en Comunidades Inteligentes".

Do not add acronyms to the title.

## Purpose

Create one integrated academic plan workflow with two connected modules:

- **Module A:** Search, verify, and systematize bibliography on CityLearn v2, MADRL, Dec-POMDP, CTDE, HAPPO, MASAC, MATD3, MAAC, MARLlib, Optuna, energy flexibility, CO2 emissions, energy costs, datasets, GitHub, and KPIs.
- **Module B:** Use Module A outputs to draft the full thesis plan following Guide N. 01 section 5.1.

Module B must not be drafted in isolation. It must use the bibliographic matrix, APA citations, antecedents, datasets, GitHub repositories, KPIs, proposed architecture, and SEAI Iquitos applicability generated by Module A.

## Mandatory Terminology

- Use **MADRL** for Multi-Agent Deep Reinforcement Learning.
- Do not replace MADRL with MARL.
- Do not use `Marco_metodologico_MARL`.
- Use exactly `Marco_metodologico_MADRL`.
- Use **MARLlib** only as the proper name of the library/framework/repository.
- Use **MARL** only when part of a proper name such as a paper, repository, challenge, library, or framework.
- Distinguish **CityLearn v2** as the existing base environment from **CityLearn v3 propuesto** as the experimental thesis extension.
- Never state that CityLearn v3 exists officially outside the thesis.
- Present HAPPO, MASAC, MATD3, and MAAC as proposed MADRL backends.
- Write in formal academic Spanish, third person.
- Do not invent results, DOI, links, datasets, GitHub repositories, citations, or references.

## APA Rules

- Use current APA style only; do not use IEEE.
- Cite every technical, methodological, conceptual, and antecedent claim.
- Use `(Autor, año)`, `Autor (año)`, `(Autor & Autor, año)`, and `(Autor et al., año)` correctly.
- Ensure every citation has a final reference and every final reference is cited.
- Mark missing bibliographic data as `dato bibliográfico pendiente de verificación`.
- Mark unconfirmed results as `resultado no verificado`.
